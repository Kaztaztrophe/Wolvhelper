<div><h2><b>Wolvhelper</b></h2>

<p><b>Wolvhelper</b> is an explore helper which displays result outcomes when exploring on <i>Wolvden</i>. The userscript can be installed through extensions like Tampermonkey on desktop and Stay for Safari on iOS. The .user.js file is the only file you need to install, as the .json is referenced within it.</p>

<p><b>Currently supports:</b></p>
<ul>
<li>Echoes of the Ancient event encounters</li>
<li>Universal regular explore encounters</li>
<li>Raven Traders explore encounters</li>
<li>Grasslands explore encounters</li>
</ul>
